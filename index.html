Itinerário Formativo

Disciplinas cursadas durante a graduação em Análise e Desenvolvimento de Sistemas no IFTM, com conteúdos aprendidos e análise crítica de cada uma.

Algoritmos e Programação

1º Período — Linguagem C

Fundamentos de lógica de programação, estruturas condicionais, laços de repetição, vetores, matrizes e funções na linguagem C.

Pontos Positivos

  • Base sólida de lógica que se aplica a qualquer linguagem
  • Contato com ponteiros e gerenciamento de memória

Pontos Negativos

  • Para quem já tem experiência prévia, pode ser repetitivo e pouco desafiador

Desenvolvimento Web

1º Período — HTML e CSS

Fundamentos de HTML5 semântico, CSS3, responsividade, acessibilidade web e introdução a página web.

Pontos Positivos

  • Habilidades essenciais para desenvolvimento front-end

Pontos Negativos

  • Muito básico, falta aprofundar em JavaScript e frameworks modernos para ser mais relevante no mercado

Fundamentos de Matemática

1º Período — Teoria

Teoria dos conjuntos, funções, equações, matrizes, frações, base sólida de matemática.

Pontos Positivos

  • Desenvolve raciocínio lógico e pensamento computacional

Pontos Negativos

  • Conexão com programação nem sempre é evidente de imediato

Estrutura de Dados

2º Período — Linguagem C

Struct, ponteiros, listas encadeadas, pilhas, filas, função recursiva, árvores binárias.

Pontos Positivos

  • Essencial para entender performance e otimização
  • Conteúdo cobrado em entrevistas técnicas
  • Utilização da plataforma SPOJ para prática de algoritmos e estrutura de dados

Pontos Negativos

  • Conceitos abstratos dificultam a compreensão.

Modelagem de Banco de Dados

2º Período — BrModelo

Modelagem de dados, modelo entidade-relacionamento, normalização, criação de MER e boas práticas de banco de dados.

Pontos Positivos

  • Fundamental para qualquer sistema que persista dados
  • Fundamentos de modelagem que ajudam a criar bancos de dados eficientes e bem estruturados

Pontos Negativos

  • Muito teórica, falta de prática com SGBDs reais e SQL avançado para ser mais aplicável no mercado

Linguagem Script para Web

2º Período — JavaScript

Linguagem de programação interpretada, usada principalmente no lado do cliente para criar experiências web interativas. Aprendizado de sintaxe, manipulação do DOM, eventos, funções assíncronas e introdução a frameworks modernos (Tailwind CSS).

Pontos Positivos

  • Linguagem onipresente no desenvolvimento web, essencial para front-end
  • Dando vida às páginas web, permitindo interatividade e conhecimento de frameworks modernos como Tailwind CSS

Pontos Negativos

  • Sintaxe horrível e comportamento IMPREVISÍVEL! ODEIO JavaScript!
